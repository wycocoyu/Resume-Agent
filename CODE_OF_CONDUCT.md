# Code of Conduct / 社区行为准则

## Our Pledge / 我们的承诺

Participants in the Resume-Agent (CocoCV) community are expected to maintain professional, respectful, and constructive communication, free from harassment or discrimination regardless of background, experience, or identity.

参与者应保持专业、尊重和建设性的沟通，不因身份、背景、经验或观点对他人进行骚扰或歧视。

## Unacceptable Behavior / 不可接受的行为

Unacceptable behavior includes personal attacks, threats, sustained harassment, publishing others' private information (such as personal resumes or contact details without consent), and posting API credentials or internal data in public project spaces.

不被接受的行为包括人身攻击、威胁、持续骚扰、未经授权公开他人隐私信息（如真实个人简历或联系方式），以及在项目公共空间发布 API 密钥或内部数据。

## Enforcement / 执行与处理

Maintainers may remove inappropriate content, restrict participation privileges, and handle security or privacy issues privately. Participating in this project implies agreement to abide by this Code of Conduct.

维护者可以删除不当内容、限制参与权限，并对安全或隐私问题采用私密处理。参与本项目即表示同意遵守本准则。
