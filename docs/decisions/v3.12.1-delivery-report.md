# Resume-Agent / CocoCV 全量重构与 21 项 Issue / PR 合并交付报告

## 一、交付摘要

本阶段全部代码改造、单测与端到端验证在独立分支 `feat/full-issue-pr-consolidation`（提交 `4e374d0b`）完成，后随 CocoCV v3.12.1 合入主线。

## 二、核心架构演进概览

- **Agent 底座重构（Pi-Mono 单协程事件循环 + 耐久性会话）**：以 [`backend/agent/pi_core/loop.py`](../../backend/agent/pi_core/loop.py) 单协程线性事件循环替代 OpenManus 多队列状态机制，配合 [`sse_adapter.py`](../../backend/agent/pi_core/sse_adapter.py) 与 [`context.py`](../../backend/agent/pi_core/context.py) 实现冗余工具上下文折叠、`%%SUGGESTIONS%%` 损坏 JSON 自动修复及事件流兼容翻译。
- **渐进式 TypeScript 绞杀藤底座（Strangler Fig Wave 0）**：新增 [`packages/schema`](../../packages/schema/package.json)（`@cococv/schema` Zod 数据契约）与 [`packages/proxy`](../../packages/proxy/package.json)（`@cococv/proxy` Hono 网关骨架），保留 Python 后端的 XeLaTeX 编译、FastMCP 服务与核心接口。
- **高可靠 SSE 流式解析与纯粹 ASGI 中间件（Issue #68）**：将 [`observability.py`](../../backend/middleware/observability.py) 从 `BaseHTTPMiddleware` 重写为纯 ASGI 中间件以彻底消除 `TaskGroup` 断连崩溃，为图像识别新增每 15 秒心跳的流式端点 `POST /resume/upload-image/stream`（含前端 [`uploadResumeImageStream.ts`](../../frontend/src/lib/uploadResumeImageStream.ts)），将 COS 与同步会话重试全部移出事件循环，并在 [`sync_service.py`](../../backend/services/sync_service.py) 统一 UTC 时区对齐消除同步 500 报错。
- **HTML 模板矩阵、双引擎预览与 PDF CMap 零退化**：落地 `asu-tech` 与 18 套 `variant-*` HTML 模板矩阵、离线自包含 HTML 导出与三档自动一页适配、`cococv` + `resume-agent` 双品牌 CLI 与 Chrome CDP PDF 导出、XeLaTeX `/ToUnicode` CMap 中文可复制保障，以及 4 大 Harness（Claude / Codex / WorkBuddy / pi）通用 `skillkit` 产物。
- **生态能力与界面质感升级**：提供官方 [`FastMCP Server`](../../backend/mcp/server.py)、目标岗位 JD 靶向分析与 3D 雷达图（注：工作台侧栏 JD 入口后于 Issue #99 移除）、客户端本地敏感信息与 API Key 脱敏，以及工作台与设置页设计系统更新。
